# Datasets

Every dataset the paper measures, how it is fetched, and exactly which subset
is used. **Subsets were fixed before anything was measured** and are not
changed after seeing a result; a change here is a new artifact version.

No downloaded data is committed. Each dataset has a `fetch.sh` that downloads
or generates it into `datasets/data/` (or `$COLBIN_DATA`) and checks every file
against [`MANIFEST.sha256`](MANIFEST.sha256). Generated data (TPC-H) is pinned
by the generator's commit and by the checksum of its output.

```sh
datasets/fetch-all.sh            # everything
datasets/tpch/fetch.sh 0.1       # one dataset, one subset
cd datasets/data && sha256sum -c ../MANIFEST.sha256   # verify without the scripts
```

Each dataset directory holds `LICENSE-NOTE.md` with the licence and whether
the data may be redistributed.

`datasets/synthetic` is colbin's own generated corpus. Its author shaped it to
exercise colbin's layouts, so it is not measured or reported here; it stays
for colbin's own tests.

## How a dataset is built

A dataset is a Go package under `datasets/<name>/`:

| file | what |
|---|---|
| `fetch.sh` | downloads (or generates) the data and verifies it: `source "$(dirname "$0")/../lib.sh"`, then `fetch URL PATH` / `git_at URL COMMIT DIR` / `verify PATH...` |
| `LICENSE-NOTE.md` | the data's licence, and whether it may be redistributed |
| `types.go` | the Go structs, with `cb` tags — the one schema every format is generated from |
| `load.go` | reads the fetched files into those structs |
| `types_msgp_gen.go`, `<name>gen/` | generated by `go run ./cmd/gen <name>`; committed |

Then:

1. Add the dataset's root types to `cmd/gen/targets.go`, each with an access
   path: a dotted path to one numeric field summed over every row
   (`"Orders.Lines.ExtendedPrice"`), or `""`.
2. `tools/fetch-flatc.sh && go run ./cmd/gen <name>`.
3. Add its cases to `matrix/cases.go`. A case whose files are missing returns
   `missing(...)`, so `go test ./...` passes in a clone that has fetched nothing.
4. `COLBIN_PIN=1 datasets/<name>/fetch.sh` once, to record its checksums; commit
   `MANIFEST.sha256`.
5. `go test ./matrix -run 'Sizes/<name>' -v -timeout 0` must pass: every format
   round-trips the data, every access aggregate agrees, and no signed field
   holds a negative without `pb:"sint"`.

### Rules for the types

- **The struct is what a Go programmer would write for this data**, not what
  any format prefers. Pick the narrowest Go type that holds every value the
  column can hold per the source's own schema (int32 for a 32-bit key, not
  int64), because the fixed-width formats (Arrow, FlatBuffers) pay for width
  and the varint formats do not.
- Exact types for exact data: money and decimals as integer minor units,
  dates as integer days, timestamps as integer microseconds (or whatever unit
  the source has). A float only for a value the source holds as a float.
- A nullable column is a pointer (`*int32`, `*string`). Do not invent a
  sentinel.
- A signed column that can be negative gets `pb:"sint"`, so protobuf uses its
  zigzag encoding. The matrix test fails if one is missed.
- Supported field shapes, which every generator handles: scalars, `[]byte`,
  `*scalar`, `[]scalar`, struct, `*struct`, `[]struct`, `map[string]scalar`
  (protobuf only). A shape a generator cannot carry is not forced: that format
  is reported as n/a for the root, with the reason.
- A document that cannot be given a struct is measured on the **dynamic path**
  (`map[string]any` / `[]any`, `bindDynamic` in `matrix/`), and reported as
  such. A dataset with hand-written structs says so in its `LICENSE-NOTE.md`
  and in the paper.

### What every case reports

`go test ./matrix -run Sizes` with `COLBIN_RESULTS=results` writes:

- `sizes.csv`: per case and format, bytes, bytes per row, gzip and zstd, both at level 6,
  and round-trip status;
- `cases.csv`: per case, the rows that colbin writes as tables against lists,
  the bytes the tables account for, leaf values, colbin bytes per value, the
  schema section size and gob's steady-state stream size.
